# Daily News Application

DailyNews is a responsive web application that provides the latest news from multiple categories such as Science, Entertainment, Sports, Technology, Health, Business, Fitness, and Politics. The application fetches real-time news using the News API and displays it in an organized and user-friendly interface.

##  Features
- Real-time news updates from trusted global sources  
- Category-wise news sections (Science, Entertainment, Sports, Technology, Health, Business, Fitness, Politics)  
- Fast and responsive UI built with React  
- Efficient loading states and error handling for API requests  
- Clean and maintainable code using functional components  
- Smooth navigation between different news categories  

## Technologies Used
- HTML5 – Semantic and accessible structure  
- CSS3 – Responsive and reusable styling  
- React.js – Component-based UI development  
- News API – Fetching real-time news data

##  Installation & Setup
1. Clone the repository  
   git clone https://github.com/your-username/daily-news.git

2. Navigate to the project directory  
   cd daily-news

3. Install dependencies  
   npm install

4. Create a .env file and add your News API key  
   REACT_APP_NEWS_API_KEY=your_api_key_here

5. Start the development server  
   npm start
